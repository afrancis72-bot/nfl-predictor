# NFL Predictor Pro

Streamlit NFL DraftKings DFS research app.

Current repository snapshot includes Week 4 2026:
- V8 correlated 50,000-run Monte Carlo simulation
- V4 air-yards/red-zone component projections
- verified game-environment file
- ownership/leverage model
- DST model
- diversified portfolio optimizer

## Run locally
```bash
pip install -r requirements.txt
streamlit run app.py
```

## Important
This is a research/DFS decision-support model. Before contest entry, refresh and verify
active rosters, injuries, DraftKings salaries, late news, ownership and game environment.
