# PGA Predictor Pro V10.8.0 — Unified PGA Dashboard

UI/navigation redesign built on the working V10.7.2 official PGA TOUR TeeTimes API release.

## Navigation
- Setup / Inputs — single control center for weekly files, course and weather.
- Tournament DFS — rankings and portfolio generation only.
- Round Parlays — official grouping pull, round simulation and 6-leg tickets; manual fallbacks collapsed.
- Course DNA — transparent reconstruction of the visible OTIS Course-Fit component emphasis plus plain-English thesis.
- Results / Calibration — current outputs and future calibration home.

## Modeling
No predictive-model, simulation, optimizer, push-rule or grouping-API methodology was intentionally changed in this release. Course DNA is an audit/reconstruction from visible weekly APP/OTT/ARG/PUTT/History component scores and is explicitly labeled as such; unavailable granular data is never invented.
